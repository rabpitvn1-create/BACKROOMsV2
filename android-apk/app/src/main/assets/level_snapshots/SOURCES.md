# Level Snapshot image sources

The APK packages these images locally so the Snapshot frame works offline and
does not request an external image at runtime. All files are original artwork
generated with ChatGPT in the VIBECODEΩ project (chat "Art BACKROOMsV2 R01")
on 2026-11-09: Level 7 first, then Levels 0, 1, 3 and 5, then Levels 2, 4
and 6, replacing the images retrieved from the Escape the Backrooms Wiki CDN
on 2026-08-20. Level 8 reuses the Level 7 image; there is no Level 9 image
yet, so Level 9 falls back to the Level 7 image as well.
