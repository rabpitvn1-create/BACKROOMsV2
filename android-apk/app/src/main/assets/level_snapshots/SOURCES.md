# Level Snapshot image sources

The APK packages these images locally so the Snapshot frame works offline and
does not request an external image at runtime.

Level 0 uses the four pixel-art images supplied in the project Google Drive
folder. The source PNG files are converted to WebP for APK packaging while
keeping the same 768x448 frame. Level 0 cycles through the four local images by
turn. Levels 1-6 keep the existing Escape the Backrooms Wiki assets retrieved on
2026-08-20.
